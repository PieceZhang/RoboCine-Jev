SAM 完成 779 对参考/执行帧的传播与测量，其中 48 对存在无效 mask。无效值记为 null，未按零误差填充。遮挡、中心出画和边缘 mask 分别统计；不同有效帧覆盖率下的均值不能单独用来认定胜负。逐阶段指标、角度无效帧和逐帧数据见各组 `visual_metrics.json`。

本轮 779 个评分时刻均有有效主体 LiDAR 角度输入及可见性审计。12 组均未记录场景接触，动态球体最小几何净距为 0.1529 m；安全未通过项来自底盘角加速度超限。已人工抽查各 Jev 视频中段与末段的 [SAM 覆盖图](results/isaac_suite_05/sam_mask_contact_sheet.png)，确认 MoveIn 的触边及下降镜头末段主体出画可直接在图像中观察到。

上升运镜的部分几何代理有所改善，但两模式有效帧覆盖率不同；MoveIn 构图误差明显增加，且执行 mask 有 16 帧触边。两模式预算成功率均为 1/6，当前结果不支持 Jev 普遍降低整体意图损失的结论。分割失败统计采用缺失、空 mask 或非有限输出的自动判据，覆盖图供人工检查，不是逐帧人工真值标注。

真实 API 共记录 195 次 HTTP 请求，模型均为 perplexity；输入 token 合计 525,944。单请求平均 0.676 秒。记录 17 个数值授权、12 次方案安装，其中 7 次非零；最新状态/时限复核拒绝 3 次。规划可行批次与最终安装是两个不同统计口径。

当前“规划可行”只表示预测控制通过数值安全及执行器约束，仍可能存在较大 task-space 跟踪残差；它不能等同于目标轨迹的精确可实现率。后续需要把预测实际轨迹与 Jev 权限的一致性加入验证，完善实际速度/加速度闭环，并把相机视场与主体可见性影响反馈给语义决策。不能用扩大授权范围掩盖这些问题。

Jev 通过保护属性、修改方向、六轮数值接受性搜索、时间窗口和完整方案确认给出权限；数值确认保留原精度。数学模块检查零使用量、区间内部与边界，在硬约束通过的候选中优先最小化预测原始位姿误差及终点误差，执行质量仅作次级排序。全部修改相对原始参考记录，恢复复用同一权限/验证流程。该规划代价是几何代理，不是 SAM 指标或完整语义意图分数。

逐控制回调平均 22.56 ms、最大 511.02 ms，1408/4808 次超过 20 ms。锁步仿真中安全控制不等待 API 响应；这些数据不构成 50 Hz 实时执行保证。

配置为 headless Isaac Sim、PGS、物理 1000 Hz、WBC 50 Hz、双 PhysX 最近命中 LiDAR 10 Hz、384×288 双视频 8 fps，关闭 ROS 图和 RTX LiDAR。运行时采用 95% 速度、40% 加速度/轮加速度、15% 底盘角加速度执行余量；审计仍使用原始物理限制。`pace=.2` 只限制仿真/墙钟速率，参考预算始终 8 秒。没有验证镜头结束后的完全停稳。

已修复 URDF 导入模板在世界原点成为额外碰撞体的问题。`import_collision_audit.json` 逐次断言 20 个真实机器人碰撞体保持有效，`initial_raycast_audit.json` 留存射线身份。此处采用 [OpenUSD class 语义](https://openusd.org/release/glossary.html#class) 隔离模板库。

适用边界：当前是 JVS 差速底盘与六轴臂上的有限 task-space 候选搜索，尚非任意环境的完备路径规划器；完整自碰撞证明、旋转主体估计、多镜头衔接和真实硬件实时性均未验证。主体初始位置/静止朝向由场景标定提供，主体点云关联使用仿真身份辅助，角度评分使用逐帧 LiDAR 位置估计。障碍未来真值没有输入 Jev 或规划器。动态跟踪仅估计水平平移，射线未模拟材质与噪声。物理峰值和遮挡/视觉退化仍需依据本表继续处理，不能把目标轨迹处于权限内等同于实际执行没有偏差。

不启用避障的理想运动学反事实在六组场景均出现几何相交，见 [nominal_counterfactual.json](results/isaac_suite_05/nominal_counterfactual.json)。它只验证场景确有避障需求，不计入 PhysX 验收。
