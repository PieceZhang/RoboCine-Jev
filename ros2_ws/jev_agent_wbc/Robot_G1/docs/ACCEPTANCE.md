本目录的验收范围仅为 G1 基础行走。暂不连接 Agent、ROS2 避障或相机轨迹。

预先固定的验收工况：先站立4秒，随后前/后/左/右/斜向/正负yaw各8秒，最后停住5秒。共65秒。速度在机身坐标系下定义，单位m/s、rad/s，见 config/commands.json。指令变化用加速度限制平滑：XY 0.35m/s²，yaw 0.6rad/s²。

每段去掉前2秒后，测量实际机身速度均值、相对目标的RMSE。一般段的XY均值向量误差<0.16m/s，yaw均值误差<0.2rad/s；站立/停止段分别<0.08m/s与<0.12rad/s。整个运行（包含启动与转向过渡）根部高度≥0.55m、|roll|与|pitch|≤0.5rad，状态、关节与策略输出均有限，且无中途重置。所有项目通过才设置 stable_multidirection_pass=true。超过0.9rad倾斜或高度低于0.45m时提前停止并记录跌倒。

物理频率200Hz，策略50Hz，严格复用官方训练dt与decimation。每个观测项保留5帧，顺序为角速度、重力方向、速度指令、14关节相对位置、14关节速度、14上一动作；每项历史由旧至新，按项拼接为255维。动作14维，offset/scale=0.5与关节顺序来自官方IO YAML。电机模型直接导入固定AGILE源码的G1_29DOF_DELAYED_DC_MOTOR。

地面为本地生成的200×200×0.1m静态方块，顶面严格为z=0（中心z=-0.05m），不引用远程Grid/纹理；静/动摩擦系数1.0，反弹0。机器人采用官方G1 PhysX、无左右手变体；初始根部高度0.78m，其余初始状态来自官方配置。上半身维持默认姿态，关闭训练时的随机上半身动作、地形随机化与扰动。仿真运行后不写根部姿态或速度；机器人移动仅由预训练策略与关节电机产生。

pace=1要求按正常物理时间推进；若计算超过预算不放慢物理时间步长，报告sim_seconds/wall_seconds的实测实时比。策略与PhysX使用CPU，可绕开本机原有torch2.7+cu126对RTX5090的CUDA核支持问题；Kit仍使用NVIDIA GPU。独立venv只读继承用户已装的Sim5.1，不修改原有conda环境。
