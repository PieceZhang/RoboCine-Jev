# Husky A200 + UR5：真实车轮物理与末端相机控制

本目录新增四轮滑移转向 Husky、UR5 六轴及固定 Robotiq 2F-140 工具。模型、安装参数、来源与本次测试结果均独立保存在本目录；底层运行器位于 `../scripts/mobile_manipulator/`，不依赖其他 `Robot_*` 目录或上游 Agent。

当前结论：完整证据 `results/acceptance_05/` 的整机运动、机械臂独立控制、相机 WBC、停车与实际相机渲染均通过；共享控制器最后增加软限位代价后，另通过 `results/wbc_soft_final/` 的 20 秒 WBC 诊断。有限 31 个无机器人自碰撞采样姿态的相机检查通过。LiDAR 仍有漏检，连续全姿态覆盖、避障闭环与完整带扫描运行的实时计时尚未通过，不能把本目录视为已经完成全部目标的部署。

Husky 不能直接横移。左／右／斜向行驶使用实际轮关节完成转向后前进；运行中读取 PhysX 底盘位姿闭环修正朝向。机械臂独立测试保持车轮停车，WBC 联合求解前进速度、yaw 速度及六个 UR5 关节速度，并控制包含安装外参的实际相机光心与姿态。所有动作通过有限力矩的关节驱动执行，没有逐帧设置底盘位姿。

## 运行

```bash
cd /home/w84384651/Documents/.RoboCine-Jev/ros2_ws/jev_agent_wbc/Robot_Husky_UR5
./run.sh --sensor-audit --sensor-rgb --output results/new_acceptance
./run.sh --probe --sensor-audit --sensor-rgb --output results/new_probe
./run.sh --coverage --poses 64 --output results/new_coverage
```

输出目录必须尚不存在。默认使用本机已安装的 Python 3.11／Isaac Sim 5.1；可设置 `ISAAC_PYTHON`。实际 GPU 执行需要可访问 RTX GPU 的环境。物理频率固定 100 Hz，`pace=1`；运行速度与任务质量分别判定。`--probe` 只做短时前进诊断；`--coverage` 运行独立的有限姿态传感器检查，不计作连续运动或全姿态证明。

`tested_scene.usda` 保存展开后的独立场景几何；执行器增益及力矩限制通过运行器写入，准确值同时保存于 `configuration.json`。复验需要使用启动入口与对应源码／配置快照，单独打开导出场景并播放不构成相同执行器配置的复验。

也可在 Isaac Sim 直接打开 `assets/husky_with_sensors.usda` 检查带传感器的装配：原始刚体层级下已经包含末端 `CineCameraOptical/Camera`、底盘 `CineLidar_main` 与 `CineLidar_aux`，两台扫描器节点带相同的采样和量程属性。这个薄装配层引用版本化 v2 模型，不修改运行模型或配置。它提供可视相机和 LiDAR 安装节点；扫描数据仍由 `run.sh` 的 PhysX 最近命中采集实现，不是额外的 RTX LiDAR 插件。`assets/sensor_assembly.json` 保存模型／配置／装配哈希及外参；`results/sensor_assembly_preflight.json` 已通过 CPU 层级和外参矩阵核对。需要重建时运行 `scripts/build_sensor_assembly.py`，使用相同 Isaac Python。

可通过 `--trajectory /绝对路径/camera.json` 输入独立的带时间 6D 相机参考。JSON 为至少两个元素的数组，每个元素包含 `t_s`、三维 `position_m`、单位四元数 `quaternion_xyzw`，使用世界坐标下相机光学帧；时间从 0 严格递增。位置按时间插值、旋转使用 Slerp，WBC 在实测反馈下跟踪，不需要上游规划器。该接口验证数据格式，不保证任意轨迹可达或无碰撞。

## 模型与可追溯修复

来源：[ppppplus/husky_ur5_isaacsim](https://github.com/ppppplus/husky_ur5_isaacsim)，固定提交 `55ba4ef84935981cb5367e233ab72ab2b34f1579`。原始完整 USD、对应 URDF 和声明文件保存在 `assets/source/`，准确 URL、大小和 SHA256 见 `ASSET_MANIFEST.json`。USD 不依赖远程模型，只有 Isaac 自带 `OmniPBR.mdl` 材质依赖。保留来源声明：仓库没有顶层许可证；Husky 描述包声明 BSD，UR5 包声明 BSD-2.0。

原始 USD 在当前 Isaac Sim 上出现零指令漂移、翻转，实测安全门限中止于 1.77 秒。检查发现 Husky 的 46.034 kg 惯性链接被写成极小转动惯量、顶部盖板被写成 50 kg，多个其他惯量缺失。`prepare_assets.py` 在独立叠加层恢复配套固定版本 URDF 的质量、质心及完整惯性张量，经特征分解写入主惯量和主轴；原始文件不修改。

当前入口使用版本化 `assets/husky_ur5_v2.usda`：明确写入配套 URDF 尺寸与安装位置一致的两块车体碰撞盒，修正原始碰撞包围盒被尺寸重复缩放及圆柱包围盒的问题。原始物理盒的 `size=1`、缩放为 URDF 尺寸，物理尺寸本身正确；出错的是其显式 `extent`，会影响几何审计。原始视觉与车轮滚动关节保留。`assets/husky_ur5.usda` 留存早期验收使用的叠加层，哈希仍与对应历史结果一致；不能用早期模型的通过结果替代当前版本复测。

本任务无需夹爪开合，因此在其原始几何姿态将夹爪固定为刚性工具，删除冗余闭链约束；UR5 六轴及四个滚动车轮均保留。原始 ROS 控制图停用，防止竞争驱动。启用 PhysX 本体碰撞，只过滤同一固定连接组件内部的几何对，保留移动连杆的本体接触。全部叠加层修复与固定组件过滤对见 `assets/repairs.json`。这里没有实现自碰撞距离约束 QP，碰撞接触不能替代规划安全证明。

车轮半径 0.1651 m、轮距 0.5708 m、轴距 0.512 m 均取自配套描述。滑移转向具有真实轮胎侧滑；几何轮距没有通过虚构横向自由度代替。UR5 实际位置界限为各关节 ±2π、肘关节 ±π；执行速度保守限制为 0.65 rad/s，力矩限值为 150／28 Nm。车轮的 100 Nm 驱动限值属于仿真配置，尚未做实机执行器标定。

## 传感器与验收范围

`sensors.json` 安装一个 UR5 腕部相机和两个机身固定 LiDAR（主 + 一个辅助）。两台扫描器使用完全相同的 360 个方位、−80°～80° 共 81 个俯仰角、0.05～10 m 量程，共 29160 条射线／扫描。当前扫描器实现为 PhysX 最近命中射线，保留本体遮挡；不能称为 RTX LiDAR 波形、材质回波或噪声验证。

最终相机相对 `ur5_wrist_3_link` 平移为 `[-0.04, 0, 0.34] m`，光轴沿腕部 `+Z`、图像上方向沿 `−Y`；实际光心外参参与 WBC Jacobian。机身扫描器相对 `husky_base_link` 位于 `[0.53, 0.40, 0.42] m` 与 `[-0.53, -0.40, 0.42] m` 两个对角外侧。安装仍是无附加载荷的原型，支架、供电线缆和实机载荷尚未建模。

`results/preflight.json` 已通过真实叠加 USD 的 CPU 静态检查：六个原始文件哈希一致、四个滚动车轮 + 六个机械臂自由度、关节界限正确、本体接触启用、质量与惯量修复、两个 LiDAR 参数相同。该检查不属于物理或渲染验收。

`results/probe_04/` 实际执行 5 秒，前进位移 0.220829 m、最大机身倾角 0.003255 rad，实际相机渲染与正向探针通过；该短诊断尚未启用后续的本体接触配置，不作为最终全功能验收。`results/probe_01..03/` 保留路径、碰撞包围盒目的标识和原始惯量问题的失败证据。

`results/acceptance_01/` 在启用本体接触后稳定完成前／后移动，左转因真实滑移在 18 秒预算内仍差 0.121 rad 而失败，门限未放宽。后续验收使用测量朝向 PI 控制与更长、有限的转向时间预算。最终物理、传感器与计时结论应分别读取最新结果中的 JSON；成功运动或清晰的单张图不能证明全关节空间无碰撞、所有姿态视野无遮挡或信息足以可靠避障。

`results/acceptance_02/` 在保留的 v1 模型上完整通过六方向、机械臂独立控制和 6D 相机 WBC；独立重算审计也通过 17973 个连续 100 Hz 样本、关节界限、刚性变换、源码快照哈希与最终停车。方向横向误差最大 10.54 mm；机械臂独立控制时底盘漂移 0.658 mm；WBC 位置 RMSE／最大值 6.122／11.961 mm、姿态 RMSE 0.008458 rad，底盘跨度 0.10775 m。仿真 179.73 秒、实测运行 284.06 秒，计时未通过。这是历史版本证据，当前 v2 的最终结论以重新执行的结果为准。

`results/coverage_candidate_01/` 记录 v2、外置双 LiDAR 与中间相机安装 `[0,0,0.30] m` 的完整 77 姿态检查；检测 27461／27720 个环形障碍目标，仍有漏检。该配置仅作对比，未通过整体验收。一次有限 27 安装位置搜索后，`results/camera_final_01/` 使用最终相机安装真实渲染全部 77 姿态，其中 31 个机器人自身无非相邻碰撞的采样姿态，相机均为零本体遮挡像素、零相机壳体干涉。其余采样含机器人本身自碰撞，不属于可执行安全姿态；未缩小任何原生关节限位。这个有限采样结果仍不能证明连续全姿态覆盖；最终相机检查没有重做 LiDAR 环测，也没有消除已知扫描盲区。
